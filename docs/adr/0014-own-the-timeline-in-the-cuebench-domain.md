# Own the timeline in the CueBench domain

CueBench will use the native video element as the authoritative playback clock and integer milliseconds as canonical Media Time. A CueBench-owned timeline engine will render a precomputed waveform and separate caption and audio-description tracks from one shared time-to-pixel transform. Dragging or keyboard adjustment creates an Edit Preview and commits at most one version-guarded domain command on completion; visual regions never form a second mutable project model. A semantic cue and beat list provides the complete keyboard and assistive-technology alternative to the visual timeline.
