# Separate generation from WebMCP remediation

CueBench AI will generate complete initial caption and audio-description proposals, while the Browser Agent uses WebMCP to inspect evidence, remediate bounded problems, revalidate tracks, and assist the human certification workflow. This preserves reliable whole-video generation and long-video scalability without reducing WebMCP to a trigger for backend automation; generated content remains Proposed and is attributed to CueBench AI until a person rules on it.
