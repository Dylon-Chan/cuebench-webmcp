# Operate the public demo with bounded private observability

CueBench will separate local, preview, and production bindings, storage, secrets, quotas, and cleanup rules. Anonymous limits are configurable and initially allow 30 processed media-minutes, six Generation Runs, and 50 Narration Previews per signed session per 24 hours, in addition to the global spend circuit breaker. First-party operational telemetry may retain salted identifiers, stage timing, cost, media size and duration, status, and error codes, but never caption text, frame content, filenames, or media URLs.

The bundled original 90-second teaching sample will support both real generation and an explicitly labeled deterministic replay fallback so an external outage does not prevent judges from completing the collaboration flow. Impact is reported through local project evidence rather than invented time-savings claims. Project deletion remains human-only and confirmed: it cancels active work, requests immediate cloud-artifact deletion, removes IndexedDB data, and reports any cleanup that remains subject to lifecycle enforcement.
