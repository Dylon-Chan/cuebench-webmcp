# Use WebMCP for live session-dependent work

CueBench will use backend APIs, local tools, or conventional MCP for page-independent media processing such as transcription, frame analysis, TTS, and mixdown. WebMCP will expose operations whose meaning depends on the open CueBench session—selection, playhead, visible evidence, quality findings, review state, revisions, and human confirmation—so a person's existing browser agent can remediate the shared artifact without a separate CueBench integration.
