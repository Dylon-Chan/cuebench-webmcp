# Keep Core WebMCP narrow and focus-sensitive

CueBench Core will keep a small always-registered surface for project and bounded timeline inspection, findings and visible focus, separate caption and audio-description generation, full validation, track export, Quality Profile proposals, and certification preparation. An active Generation Run replaces the generation starters with inspection and cancellation. Exactly one dynamically registered family may expose caption-cue, audio-description-beat, or undescribed-gap inspection and remediation for the visible selection; the previous family's `AbortSignal` is aborted first.

Scoped mutations require the expected selected item, item revision, and project revision. Reopening Sustained work or replacing existing proposals awaits cancellable in-page human confirmation. Merge is adjacent-only. Agent Ready is a Browser Agent attestation in Core. Sustain, Object, apply profile, waive warning, certify, media replacement, backup import, generic editing, and bulk fixing are never registered. A sanitized opt-in WebMCP inspection drawer exposes registrations and call history for testing and judging.

Professional Scale may later introduce Secondary Agent Review and a mutually exclusive Batch Automation Mode. Those future capabilities must not let the generating pass attest to its own output, overlap a generic editor with Core's scoped mutations, or acquire human-ruling authority.
