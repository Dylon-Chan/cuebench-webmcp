# Professional Scale

Professional Scale extends CueBench beyond anonymous short-video sessions while preserving Core Authoring's revision, evidence, ruling, and certification semantics.

## Language

**Durable Workspace**:
An authenticated cloud workspace that stores projects, media, permissions, processing jobs, and certified outputs across devices and collaborators.
_Avoid_: Anonymous project, browser backup, processing copy

**Secondary Agent Review**:
A future quality-review pass performed by an agent that did not generate the reviewed revision and may assign Agent Ready when it can link its attestation to evidence and validation results.
_Avoid_: CueBench AI self-approval, human ruling, certification

**Automated Agent Attestation**:
The Agent Ready transition created by Secondary Agent Review and recorded with the reviewing agent, reviewed revision, evidence, validation state, and model provenance.
_Avoid_: Sustained, automatic certification, generation success

**Batch Automation Mode**:
An explicit future operating mode for large projects that replaces Core's selection-scoped mutation tools with a mutually exclusive, version-guarded batch surface for a bounded track or finding set.
_Avoid_: Default WebMCP surface, hidden bulk edit, concurrent generic editor

**Batch Patch**:
An atomic, previewable collection of item revisions proposed in Batch Automation Mode. It may prepare work for review but cannot issue rulings, apply waivers, or certify a project.
_Avoid_: Bulk ruling, direct overwrite, fix-all command
